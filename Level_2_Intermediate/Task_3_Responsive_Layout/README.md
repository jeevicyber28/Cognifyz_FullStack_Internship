# Task 3: Advanced CSS Styling and Responsive Design

A responsive multi-section specialty coffee roastery webpage combining Bootstrap 5.3 grid/components with custom CSS variables, keyframe animations, card transitions, and an interactive cupping reservation form.

## Features
- Multi-section editorial layout: sticky frosted navbar, split hero card stack, sourcing grid, filterable roast catalog, 4-step pour-over timeline, FAQ accordion, and booking section.
- Custom CSS transitions, hover lifts, `@keyframes` animations, and responsive mobile breakpoints alongside Bootstrap 5.3.
- Interactive roast profile filter, Bootstrap brew-spec modal, and Express tasting booking endpoint (`POST /api/tasting`).

## Run Locally
```bash
npm install
npm start
```
Open `http://localhost:3003`.
